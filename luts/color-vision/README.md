# LUT для людей с нарушениями цветового зрения

Таблицы для поля **LUT** во вкладке «Настройки» HERITAGE3D Viewer.

> **Статус доказательности.** Профили `simulation/` основаны на опубликованных
> моделях цветового зрения и пригодны для проверки интерфейса. Профили
> `correction/` — экспериментальный прототип HERITAGE3D: их математическая
> корректность и формат проверены, но улучшение работы реальных пользователей
> клиническим или поведенческим исследованием не подтверждено. Они не должны
> включаться по умолчанию или называться лечением/компенсацией. Научный разбор,
> результаты аудита и готовые сторонние наборы: [RESEARCH.md](RESEARCH.md).

## Что в папке

| Папка | Назначение |
|---|---|
| `correction/` | **Экспериментальная коррекция**: перенос части цветового различия в светлоту; ожидаемый эффект зависит от изображения и особенностей зрения пользователя. |
| `simulation/` | **Симуляция**: автор видит приближение восприятия при заданном нарушении и проверяет свои цвета (POI, подписи, палитры отладки). |
| `neutral-16.png` | Нейтральная таблица: картинка не меняется. Нужна для проверки. |

Каждая таблица есть в двух форматах:

- `*-16.png` — полоса 256 × 16, 16³ узлов, раскладка Unreal, sRGB. **Для просмотрщика используйте этот файл.** Только такой размер правильно читает этап постобработки PlayCanvas (CameraFrame `colorLUT`).
- `*-33.cube` — Adobe/IRIDAS `.cube` 33³, вход и выход — экранный sRGB. Для Photoshop, DaVinci Resolve, OBS и других программ.

| Файл | Нарушение | Доля мужчин, ориентировочно |
|---|---|---|
| `*-protanomaly-*` | Протаномалия — ослабленное восприятие красного | ≈ 1 % |
| `*-protanopia-*` | Протанопия — нет восприятия красного | ≈ 1 % |
| `*-deuteranomaly-*` | Дейтераномалия — ослабленное восприятие зелёного | ≈ 5 % |
| `*-deuteranopia-*` | Дейтеранопия — нет восприятия зелёного | ≈ 1 % |
| `*-tritanomaly-*`, `*-tritanopia-*` | Ослабленное или отсутствующее восприятие синего | < 0,01 % |
| `simulation-achromatopsia-*` | Ахроматопсия — только симуляция, скорректировать нельзя | < 0,01 % |

## Как подключить

1. Вкладка **Настройки** → раздел **ПОСТОБРАБОТКА** → **Загрузить LUT**.
2. Выберите `correction/correction-<вид>-16.png`.
3. Ползунок **Сила LUT**: начинайте с малого значения; `1` — полное применение таблицы.

Коррекционный профиль следует показывать как добровольную настройку с возможностью
мгновенно сравнить результат с оригиналом. Тип нарушения и подходящая сила эффекта
не должны определяться приложением автоматически.

## Как это работает

**Симуляция** — модели, рекомендованные DaltonLens: Machado, Oliveira, Fernandes (2009) для аномалий красного и зелёного, Viénot, Brettel, Mollon (1999) для протанопии и дейтеранопии, Brettel, Viénot, Mollon (1997) для тритан-нарушений.

**Экспериментальная коррекция** — кодирование частью светлоты. Таблица добавляет
к L\* долю оси a\* для протан-/дейтеран-профилей или b\* для тритан-профилей:
L\* + k · a\* (или b\*). Это инженерная эвристика, а не опубликованный и
валидированный метод. Кроме того, a\*/b\* CIELAB не совпадают буквально с
«потерянным каналом» конкретного наблюдателя.

Классическая коррекция Fidaner была проверена локальным численным тестом и дала
неоднозначный результат. Это не основание считать её опровергнутой: небольшое
независимое исследование Simon-Liedtke и Farup (2016) поставило Fidaner на второе
место среди четырёх методов для группы с дейтеран-нарушениями. Для выбора между
методами нужен тест на задачах HERITAGE3D с реальными пользователями.

## Проверка

Ниже приведён только **модельный прокси-тест**, а не результат испытания на людях:
разница цветов пары (ΔE\*ab, CIELAB) после симуляции нарушения — без коррекции →
с коррекцией. Порог 10 используется как грубая инженерная эвристика.

| Вариант | красный / зелёный | оранжевый / жёлто-зелёный | коричневый / тёмно-зелёный | розовый / серый | синий / зелёный | Сдвиг цветов для нормального зрения, ΔE |
|---|---|---|---|---|---|---|
| Протаномалия | 38 → 48 | 22 → 30 | 13 → 19 | 9 → 12 | 81 → 84 | 7.9 |
| Протанопия | 33 → 53 | 20 → 37 | 9 → 22 | 3 → 13 | 88 → 93 | 12.1 |
| Дейтераномалия | 25 → 34 | 16 → 24 | 12 → 16 | 11 → 12 | 80 → 84 | 7.9 |
| Дейтеранопия | 7 → 32 | 7 → 24 | 8 → 17 | 11 → 13 | 84 → 89 | 12.1 |
| Тританомалия | 90 → 90 | 54 → 54 | 41 → 41 | 32 → 32 | 43 → 46 | 4.7 |
| Тританопия | 84 → 84 | 50 → 45 | 37 → 38 | 32 → 32 | 16 → 29 | 8.0 |

Точность таблицы 16³ в просмотрщике (эмуляция выборки PlayCanvas, 20 000 случайных цветов): средняя ошибка 0,5 уровня из 255, p95 — около 2 уровней.

## Ограничения

- Таблица — глобальное преобразование цвета, спроектированное для разведения некоторых типичных пар (красный / зелёный, оранжевый / жёлто-зелёный, коричневый / зелёный). Она не возвращает цветовое зрение и может сближать другие пары: в модельном тесте на случайной палитре число пар ниже выбранного порога при некоторых профилях выросло.
- Коррекция меняет цвета и для людей с обычным зрением. Не используйте её при оценке цвета, в мультиспектральных слоях и при научной работе с цветом — это вспомогательный режим просмотра.
- Включайте коррекцию для конкретного зрителя; она не заменяет продуманной палитры (подписи, формы, светлота).
- Протан- и дейтеран-коррекция текущей версии фактически используют одинаковое
  преобразование внутри каждой степени тяжести; индивидуальные различия не
  учитываются.
