# Профили LUT «Цветовое зрение»

Готовые к загрузке в HERITAGE3D Viewer таблицы цвета для проверки нарушений цветового зрения и экспериментальной пользовательской коррекции. Список профилей с названиями (ru, en, zh) и описаниями — в `manifest.json`.

> Симуляционные профили основаны на опубликованных моделях. Коррекционные профили
> являются экспериментальной эвристикой HERITAGE3D и пока не подтверждены
> пользовательским исследованием. Полное научное обоснование находится в
> `luts/color-vision/RESEARCH.md` исходного репозитория.

## Формат

Все файлы — PNG 256 × 16: горизонтальная полоса из 16 срезов 16 × 16, раскладка Unreal (x = синий · 16 + красный, y = зелёный, верхняя строка — 0), sRGB. Именно этот размер принимает постобработка PlayCanvas (`CameraFrame.colorLUT`). Загружать как sRGB-текстуру, фильтрация линейная — как сейчас делает `viewer.loadColorLut()`.

Проверено: `simulation-deuteranopia` загружен в развёрнутый плеер через `viewer.loadColorLut()` на сцене Kronstadt (WebGPU); результат совпал с расчётным в среднем до 1,4 уровня из 255.

## Для интеграции в плеер

- В разделе «Постобработка» используется один список «Профиль CVD». Назначение
  указано после нарушения: например, «Дейтеранопия — комп.» и
  «Дейтеранопия — сим.». Вариант «Без профиля» снимает эффект.
  Ручная загрузка LUT сохранена.
- Список берётся из `manifest.json`: `profiles[].file`, `title[lang]`, `description[lang]`, `kind` (`correction` / `simulation` / `neutral`) — по `kind` удобно сделать две группы в выпадающем списке.
- `intensity` — стартовое значение ползунка «Сила LUT», а не клиническая рекомендация (1 — полное применение таблицы).
- Профиль меняет цвета для всех: это режим просмотра для конкретного зрителя, его не стоит сохранять в файл настроек модели как обязательный.
- Таблицы рассчитаны на SDR-вывод. При включённом HDR-выводе они не применяются (как и любые SDR LUT в плеере).
